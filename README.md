# R6 TACTICS — Ranked Plan Generator Demo

This is a compact static GitHub Pages demo.

## Included
- Map + bomb site + Attack/Defense + 1–5 player stack
- Curated, non-random plan archetypes
- 5 operator roles with execution flow
- Alternatives
- Personal notes stored locally in browser
- Dark / yellow tactical UI
- No backend required

## Important data note
Data model refreshed for the current 2026 context; Ranked/map availability can change with seasonal patches. Strategy cards are curated pro-inspired/community-informed templates, not claims that a named team used the exact five-operator lineup.

## Deploy
Upload `index.html` and `style.css` to the root of a GitHub repository, then enable Pages from `main / (root)`.
